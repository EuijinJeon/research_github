## 1. 학습된 모델

깊이 축은 **총 ReLU 유닛 수를 맞춰서** 비교한다. 유닛 수가 다르면
"층이 깊어서"인지 "유닛이 많아서"인지 구분할 수 없다.

| dataset | hidden | units | train | test |
|---|---|---|---|---|
| moons | [64] | 64 | 0.9925 | 0.9950 |
| moons | [32,32] | 64 | 0.9947 | 0.9950 |
| spiral | [64] | 64 | 0.9472 | 0.9550 |
| spiral | [32,32] | 64 | **1.0000** | **1.0000** |
| mnist | [128] | 128 | 1.0000 | 0.9770 |
| mnist | [64,64] | 128 | 0.9998 | 0.9752 |

**관찰:** spiral에서 1층(95.5%)과 2층(100%)의 격차가 크다. 유닛 수가 같은데도 그렇다.
나선 경계를 직선 64개의 arrangement만으로 감싸는 것이 어렵다는 뜻이고,
깊이 축이 실제로 유의미한 대조라는 첫 증거다.

**affine 항등식 검산:** 6개 모델 전부 `A_r·x + b_r == model(x)` PASS.
최대 상대오차 ~1e-6 (float32 정밀도 수준).

## 2. 영역 추출 — 핵심 관찰

| setting | split | inputs | regions | R/N |
|---|---|---|---|---|
| moons [64] | train | 3,200 | 454 | 0.142 |
| moons [32,32] | train | 3,200 | 589 | 0.184 |
| spiral [64] | train | 3,199 | 348 | 0.109 |
| spiral [32,32] | train | 3,199 | 602 | 0.188 |
| **mnist [128]** | train | 60,000 | **59,978** | **1.000** |
| **mnist [64,64]** | train | 60,000 | **59,981** | **1.000** |

### MNIST의 R/N = 1.000 이 뜻하는 것

**입력 6만 개가 6만 개의 서로 다른 활성 패턴을 갖는다.** 겹치는 게 사실상 없다.

이건 concepts.md §1.4에서 예상한 것의 극단적 확인이다. 결과적으로:

- MNIST에서 "영역을 클러스터링한다" = **"데이터 포인트를 클러스터링한다"** 와 같다.
- 따라서 Stage 1이 MNIST에서 재는 Ω는 함수의 성질이 아니라
  **함수 + 데이터 분포**의 성질이다. 이 구분을 놓치면 숫자를 과대해석하게 된다.
- 반대로 2D는 R/N ≈ 0.11~0.19 — 입력 5~9개가 영역 하나를 공유한다.
  여기서는 "영역"이 데이터와 독립적인 대상으로서 의미를 갖는다.

이 비대칭이 두 세팅을 모두 쓰는 실질적 이유다.

## 3. 검증 결과 (예측을 먼저 적고 확인)

### P1~P4: 폴리토프 분할 (격자 800x800, 범위 ±3.5)

| 예측 | moons | spiral | 판정 |
|---|---|---|---|
| **P1** h=[64] 경계점이 첫 층 직선 위 | **100.00 %** | **100.00 %** | PASS |
| **P2** h=[32,32] 같은 비율 (낮아야 함) | 51.44 % | 58.79 % | PASS |
| **P3** h=[64] 영역 수 ≤ 2,081 | 1,326 | 1,390 | PASS |
| **P4** h=[32,32] 영역 수 > 529 (첫 층 상한) | 1,881 | 1,862 | PASS |

경계점까지의 중앙 거리: h=[64] 0.0032 / h=[32,32] 0.0069~0.0109 (격자 간격 0.0088).

**P1의 100.00%가 핵심이다.** 1 hidden layer에서 영역 경계는 `W1`의 행이 정의하는
직선 **외에는 없다**. 이론이 코드로 정확히 재현됐다.

**P2의 ~55%**는 h=[32,32]에서 경계의 약 절반이 첫 층 직선 위에 없다는 뜻 —
그 절반이 둘째 층이 만든 경계다.

산출물: `artifacts/figures/polytopes_{moons,spiral}.png`

### P5: 볼록성 (선분 200개 × 4000 스텝)

| setting | 평균 통과 영역 | 최대 | 위반 | 판정 |
|---|---|---|---|---|
| moons [64] | 22.4 | 50 | **0** | PASS |
| moons [32,32] | 24.6 | 69 | **0** | PASS |
| spiral [64] | 18.7 | 41 | **0** | PASS |
| spiral [32,32] | 26.0 | 58 | **0** | PASS |
| mnist [128] | 63.4 | 90 | **0** | PASS |
| mnist [64,64] | 62.4 | 96 | **0** | PASS |

**영역은 깊이와 무관하게 볼록 다면체다.** 784차원에서도 위반 0.

이 테스트가 중요한 이유는 **입력 차원에 무관**하다는 것이다.
폴리토프를 그릴 수 없는 MNIST에서도 구조를 검증할 수 있는 첫 도구다.

부수적으로 얻은 값: **MNIST에서 데이터 포인트 두 개를 잇는 직선이 평균 63개 영역을 지난다.**
2D(19~26개)의 2.5~3배다. 그림 없이 영역 밀도를 재는 방법이 된다.

## 4. 여기까지의 결론

`f(x) = A_{r(x)}·x + b_{r(x)}` 라는 재작성이 **부동소수점 정밀도 수준에서 정확**하고,
그 영역 구조가 이론(Zaslavsky 상한, 볼록성, 꺾임 위치)과 **정량적으로 일치**한다.
Stage 1의 나머지(클러스터링, ε-path)가 이 위에서 진행될 수 있다.

동시에 **Ω를 낮추기 어려울 것이라는 신호**가 이미 나왔다:
MNIST의 R/N = 1.000은 병합 전 출발점이 K = N = 60,000 이라는 뜻이다.
여기서 K를 의미 있게 줄일 수 있는지가 Stage 1의 실질적 질문이 된다.
