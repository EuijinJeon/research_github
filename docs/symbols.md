# 기호표

이 프로젝트에서 쓰는 모든 기호의 **정의 원본**. 다른 문서는 여기를 참조한다.

`scripts/build_docs.py`가 이 표를 읽어서, 문서를 HTML로 만들 때
백틱으로 감싼 기호(`` `K` ``)에 **마우스를 올리면 정의가 뜨도록** 자동으로 붙인다.
따라서 **이 표에 정의를 추가하는 것만으로 모든 문서에 반영된다.**

새 기호를 쓰기 전에 여기에 먼저 추가할 것.

---

## 문제 설정

| 기호 | 정의 |
|---|---|
| `f_θ` | 학습이 끝난 신경망. 파라미터 θ가 박혀 있는 구체적 함수 |
| `θ` | 신경망의 전체 파라미터 (모든 W와 b를 합친 것) |
| `P` | 설명(interpretation). 사람이 읽거나 실행할 수 있는 형식적 객체 |
| `⟦P⟧` | 설명 P를 실행했을 때 나오는 함수. P가 설명이려면 실행 가능해야 한다 |
| `Ω` | 설명의 복잡도. 우리가 최소화하려는 값. Stage 1에서는 클러스터 개수 K |
| `ε` | 우리가 감수하기로 한 허용 오차. 스칼라 하나가 아니라 곡선을 그리기 위한 축 |
| `ε-path` | ε을 움직이며 얻은 최소 복잡도 Ω(ε)의 곡선. **이 프로젝트의 진짜 산출물** |
| `α` | 추상화 함수. f_θ의 내부 상태를 P의 내부 상태로 보낸다 (simulation relation) |

## 신경망 내부

| 기호 | 정의 |
|---|---|
| `x` | 입력 벡터. 차원은 d |
| `z` | pre-activation. z = Wx + b. ReLU를 통과하기 직전 값 |
| `r` | 활성 패턴(binary code). r_i = 1[z_i > 0]. 유닛별 켜짐/꺼짐을 적은 비트 벡터 |
| `r(x)` | 입력 x에서의 활성 패턴 |
| `D(r)` | 게이트 대각행렬 diag(r). r을 고정하면 ReLU를 대체한다 |
| `W1` | 첫 층 가중치. 각 행이 입력 공간의 초평면 하나를 정의한다 |
| `b1` | 첫 층 절편. 초평면의 위치를 정한다 |
| `W2` | 둘째 층(1 hidden layer면 출력층) 가중치 |
| `b2` | 둘째 층 절편 |

## 영역과 유효 선형맵

| 기호 | 정의 |
|---|---|
| `A_r` | 영역 r에서의 유효 선형맵. A_r = W2·D(r)·W1. 신경망과 정확히 같은 선형 부분 |
| `b_r` | 영역 r에서의 유효 절편. b_r = W2·D(r)·b1 + b2. **빼먹으면 안 된다** |
| `A` | 유효 선형맵의 약식 표기 (어느 영역인지가 문맥상 분명할 때 A_r의 r을 생략) |
| `b` | 유효 절편의 약식 표기 (A와 같은 이유로 b_r의 r을 생략) |
| `[A_r \| b_r]` | 증강 행렬. 거리 계산과 클러스터링은 반드시 이 위에서 한다 |
| `[A \| b]` | 증강 행렬의 약식 표기 |
| `[A\|b]` | 증강 행렬의 약식 표기 (공백 없는 형태) |
| `2^h` | h비트 코드로 만들 수 있는 코드의 총 가짓수. **실제 조각 수는 이보다 훨씬 작다** |
| `1+h+C(h,2)` | 2차원에서 직선 h개가 만드는 조각 수. 일반위치에서만 등호 |
| `1 + h + C(h, 2)` | 2차원에서 직선 h개가 만드는 조각 수. 일반위치에서만 등호 |
| `2^128` | MNIST(d=784, h=128)의 영역 수 상한. h ≤ d 라 모든 코드가 실현 가능해진다 |
| `일반위치` | general position. 세 직선이 한 점에서 만나지 않고 두 직선이 평행하지도 않은 배치 |
| `h` | hidden ReLU 유닛의 개수. 활성 패턴의 비트 수이자 초평면의 개수 |
| `d` | 입력 차원. 2D 합성은 2, MNIST는 784 |
| `C(h, i)` | 이항계수. h개 중 i개를 고르는 경우의 수 |
| `N` | 데이터(입력) 개수 |
| `R` | 관측된 고유 영역의 개수 |
| `R/N` | 입력 하나당 영역 개수. 1에 가까우면 입력마다 영역이 따로 있다는 뜻 |

## 클러스터링과 ε-path

| 기호 | 정의 |
|---|---|
| `K` | 클러스터(= 조견표의 줄) 개수. 영역들을 K개로 합친다. Stage 1의 Ω가 곧 이 값 |
| `k(x)` | 입력 x가 속한 클러스터의 번호. 이걸 알려면 원본 신경망을 돌려야 한다 (라우팅 문제) |
| `centroid` | 합칠 영역들의 [A_r \| b_r]를 점 개수로 가중평균한 대표값 |
| `Frobenius` | 행렬 성분 차이의 제곱합 제곱근. 파라미터 거리. 데이터 분포와 무관 |
| `cosine` | 행 방향(판단 방향)의 각도 차이. 크기 정보를 버린다. 분포와 무관 |
| `logit 거리` | 실제 출력이 얼마나 다른가. **우리 목표와 일치하는 기준 척도.** 분포에 의존 |

## Stage 2 이후 (예고)

| 기호 | 정의 |
|---|---|
| `P_c` | 파라미터 컴포넌트. θ = Σ_c P_c 로 파라미터 자체를 분해한 조각 |
| `σ_i` | 행렬의 i번째 특이값(singular value) |
| `Schatten p-norm` | 특이값 벡터의 p-norm. p=1(nuclear)이 rank의 볼록 완화 |
| `faithfulness` | 분해된 컴포넌트의 합이 원본 파라미터를 복원하는가 |
| `causal importance` | 부품이 계산에 실제로 기여한 정도. 상관(correlation)과 다르다 |
